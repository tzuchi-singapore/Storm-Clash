# Storm Clash

A 2.5D hero brawler in the browser: missions, Battle Mode, Versus, Team relay and online play.

Play: https://tzuchi-singapore.github.io/Storm-Clash/

- `index.html` is the whole game (code, stages and menu art are inside it).
- `atlas_*.webp` are the fighter animation sheets, loaded by `index.html`.
- Online play connects two browsers directly (WebRTC via PeerJS).
